HabitGlo - Recent Changes
=========================

Feb 15, 2026
------------
- Fixed Paddle checkout successUrl: no longer sets a localhost redirect URL
  when running on localhost (Tauri desktop dev). This matches the guard already
  used in the HTML checkout pages (lifetime.html, monthly.html).
- Added shadcn MCP server config to .cursor/mcp.json for Cursor IDE integration.
- Installed shadcn CLI as a dev dependency.
- Upgraded Node.js from v18 to v24 LTS (required by shadcn CLI).
- Ran an extensive checkout flow audit and documented 7 issues:
    1. successUrl always set on localhost (fixed)
    2. CSP in tauri.conf.json may block Paddle.js internals (identified)
    3. Paddle failures are silent with no user feedback (identified)
    4. Download page has placeholder URLs in config.js (identified)
    5. No auto-refresh of subscription status after checkout (identified)
    6. Dual config systems (.env vs config.js) can drift (identified)
    7. successUrl redirects Tauri away from the React app (identified)
